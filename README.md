# ✅ TaskFlow | Organizador de Tarefas

O **TaskFlow** é um organizador de tarefas desenvolvido para ajudar os usuários a organizar suas atividades e acompanhar seu progresso de forma simples e intuitiva.

## 📌 Sobre o projeto

Este projeto foi criado como parte do meu aprendizado independente em desenvolvimento web, com o objetivo de praticar lógica de programação, manipulação do DOM e interação com o usuário utilizando JavaScript.

## 🚀 Tecnologias utilizadas

- **HTML5** — estrutura da aplicação.
- **CSS3** — estilização e organização visual da interface.
- **JavaScript** — funcionalidades e interatividade.

## ✨ Funcionalidades

O projeto pode incluir recursos como:

- Adicionar novas tarefas.
- Visualizar a lista de tarefas.
- Marcar tarefas como concluídas.
- Excluir tarefas.

*As funcionalidades descritas devem corresponder ao que está implementado na versão atual do projeto.*

## 💻 Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. Utilize a interface para interagir com as funcionalidades disponíveis.

## 🎯 Objetivo do projeto

Praticar conhecimentos de HTML, CSS e JavaScript, desenvolver minha lógica de programação e ganhar experiência na criação de aplicações web.
